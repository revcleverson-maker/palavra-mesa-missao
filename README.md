# Coleção Palavra, Mesa e Missão

**Cadernos de Formação Cristã Reformada**

> Palavra proclamada • Fé fortalecida • Igreja enviada

Este repositório reúne os volumes digitais da coleção **Palavra, Mesa e Missão**.

## Estrutura editorial

A partir do novo padrão editorial, cada volume semanal é composto por três cadernos complementares:

1. **Caderno 1 — Pregação e Liturgia**  
   *Preparando o Domingo*
2. **Caderno 2 — Formação Cristã e Discipulado**  
   *Vivendo a Palavra em Comunidade*
3. **Caderno 3 — A Palavra Entre Nós**  
   *Devocionais para a Semana*

Todos os cadernos devem ser publicados em quatro versões:

- **DOCX** — edição e arquivo mestre;
- **PDF** — leitura, impressão e distribuição;
- **HTML** — publicação no site;
- **Celular** — versão própria otimizada para leitura em tela pequena.

O número do volume identifica a semana/domingo e é compartilhado pelos três cadernos.
