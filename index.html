Volumes da coleção

Lista dos volumes em ordem crescente. Esta página organiza os volumes e está preparada para adicionar novos lançamentos semanais.

Como funciona

Cada volume fica dentro da sua própria pasta (ex.: volume-5/) com um arquivo index.html. Esta página principal apenas aponta para essas pastas — nenhum conteúdo de volumes foi removido.

Adicionar o próximo volume

Para lançar o próximo volume semanalmente, crie uma nova pasta chamada volume-N/ (substitua N pelo número) e coloque nela o index.html e os arquivos do caderno. Depois, adicione esta linha ao bloco acima (ou deixe que outro colaborador a adicione):

<li data-volume="8"><a href="volume-8/">Volume 8 — (abrir)</a></li>

A página já possui um script que ordena automaticamente os volumes pelo número (atributo data-volume), então não é preciso se preocupar com a posição — apenas mantenha o atributo data-volume correto.
